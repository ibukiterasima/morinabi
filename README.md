# もりナビ

料理はできたけど、どう盛り付ければいいかわからない。

そんなときは「もりナビ」。

料理を選ぶと、

「ここにメイン」
「ここに緑」
「ここに付け合わせ」

など、盛り付ける場所が表示されます。

あとは画面を見ながら、料理を置いていくだけ。

難しい知識や特別な技術は必要ありません。

いつもの料理を、少しの工夫でおしゃれな一皿に。

## 特徴

- 料理のカテゴリーから選べる
- 盛り付け例を見ながら置ける
- 難しい知識や技術は不要
- スマートフォンでも使いやすいシンプルな画面

## カテゴリー

- 定番
- カフェ風
- 和食
- 洋食
- 麺・パスタ
- うどん
- フルーツ
- デザート

## 使用方法

1. 料理のカテゴリーを選ぶ
2. 盛り付けガイドを見る
3. ガイドを見ながら料理を置く
4. おしゃれな一皿の完成

## もりナビ

「盛り付けって、どうすればいい？」

を、見るだけで解決するためのアプリです。
